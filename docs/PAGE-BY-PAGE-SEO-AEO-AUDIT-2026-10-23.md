## Classification meanings

- **PRIORITY 1 —** fix or improve before creating more pages.
- **KEEP / IMPROVE —** retain URL; strengthen intent, HTML content, FAQs and links.
- **KEEP / VALIDATE —** retain pending uniqueness or geographic accuracy checks.
- **REDIRECT REVIEW —** do not redirect until the exact destination and evidence are checked.
- **REVIEW STRATEGIC FIT —** decide whether an adjacent topic belongs in the core offer.
- **NOINDEX —** preserve intentional existing noindex unless a separate review changes the decision.

## Global standards for every indexable page

1. Main answer and service scope must be present in initial server-rendered HTML; don't depend on client-side JS for SEO-critical copy.
2. Use one descriptive H1, logical H2/H3, concise sections, lists/tables where useful, descriptive links and no paragraph walls.
3. Every relevant commercial, software and industry page should have visible FAQs that answer real buyer/search questions. Schema must match visible content; do not invent search volume or testimonials.
4. One primary URL owns one primary search intent. Improve an existing page instead of publishing a near-duplicate service × software × industry × state combination.
5. Use metadata, canonical, breadcrumbs and applicable Organization/Service/FAQ schema accurately. Keep noindex pages out of sitemap and AI discovery.
6. Commercial pages answer who can perform the work and what is included; guides/blog answer how-to and decision questions. Link between them contextually rather than copying the same content.
7. Preserve CPA-firm positioning as a delivery/outsourcing partner; the CPA firm retains client ownership, professional judgment, review and sign-off.
8. For every proposed change, record GSC page/query performance, index/canonical status, backlinks/referrals and conversion evidence when available.
