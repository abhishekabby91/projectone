## Search cluster rules

1. **Upwork comparison intent is already served.** `/blog/upwork-vs-accounstone` is the comparison page for buyers deciding between a freelancer marketplace and a direct outsourcing provider. It should remain fair and practical. Do not create another URL for “Upwork vs accounting outsourcing.”
2. **Job postings are workflow evidence, not a page template.** Convert repeated tasks into evergreen accounting questions, such as “How to reconcile AppFolio and QuickBooks Online,” rather than using a job title as an H1.
3. **Existing URL first.** Improve the current page when it already owns the intent. The property-management cluster already covers cleanup, tenant accounting, platform-to-GL reconciliation, owner statements and Yardi support.
4. **New page only after validation.** Require (a) repeated independent postings describing the same distinct workflow, (b) GSC or keyword research indicating relevant search demand, (c) SERP/competitor evidence of a separate intent, and (d) a useful page that is not a thin software/location permutation.
5. **Use the buyer's language without copying.** Capture the task, pain point, input, output, software and handoff. Do not reproduce whole job descriptions, private client details, or proprietary proposal instructions.
6. **Keep scope honest.** Do not imply Accounstone provides property management, software implementation, tax advice, return signing, or payment authorization when the service is accounting workflow support.
