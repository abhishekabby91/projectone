# Search-Intent-First Website Roadmap — 2026-10-23

**Status:** Staged strategy; no routes deleted, redirected, or newly published by this document.  
**Decision:** Improve the strongest existing intent owners before expanding page count. A URL should exist only when it satisfies a distinct buyer need and has a defensible reason to rank independently.

## Operating rule

One primary intent should have one primary URL. Supporting pages may answer a narrower software, workflow, or evaluation question, but must link to the commercial owner and must not repeat its general sales copy. Search-volume figures are not assumed unless supported by a keyword-data source. Competitor pages establish that a page pattern exists, not that demand or ranking success is guaranteed.

## Supporting pages: keep, merge, hold, or retire based on evidence

- **Keep** a software page when the software changes the actual workflow, reports, reconciliation process, or buyer's evaluation. It must be specific and link to its commercial parent.
- **Merge or re-scope** pages that answer substantially the same query with substantially the same content and no distinct search evidence.
- **Hold expansion** of state/county pages until URL-level Search Console queries, competitor results, useful local distinctions, and backlink/equivalent-destination checks have been reviewed.
- **Retain** workflow guides when they satisfy informational intent and link to the relevant commercial page.
- **Do not delete or redirect based on page count alone.** Check clicks, impressions, query overlap, backlinks, canonical/indexing state and destination equivalence first. Use a 301 only when the destination genuinely satisfies the old URL's intent; otherwise assess whether to retain, improve, or return 404/410.

## Page review scorecard

For each existing URL, record:

1. Primary buyer and intent in one sentence.
2. The one URL that should own that intent.
3. GSC clicks, impressions, CTR, average position, and queries for a consistent period when data is available.
4. Overlap with other Accounstone URLs and whether Google is alternating between them.
5. Distinctive content/deliverables, accuracy of service claims, and buyer conversion path.
6. Internal links to the parent, related services, and genuinely helpful guides.
7. Decision: **improve / keep as support / merge / hold / retire after evidence review**.

## Evidence limitations and next actions
